# 受入テスト表

- 対象: ApplyTracker
- 作成日: 2026-08-31
- 使い方: 上から順に操作して、「実際の結果」欄に ○ / × を書く。× があれば検収不合格

## 前提

- テスト用のアカウントを1つ用意する（新規登録から作る）
- ブラウザは Chrome / Edge / Safari の最新版
