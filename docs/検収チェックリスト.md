## 検収後の扱い（着手前に合意しておくこと）

| | 対応 | 費用 |
|---|---|---|
| **検収前**に見つかった仕様との不一致 | 無償で修正 | なし |
| **検収後**に見つかった不具合 | 契約不適合責任の期間内なら無償修正 | なし（期間は要合意） |
| **検収後**の仕様変更・機能追加 | 別途見積り | 有償 |
| 運用中の問い合わせ対応・監視 | 保守契約の範囲 | 月額または時間単価 |

**この4つを曖昧にしたまま納品すると、無期限に無償対応を求められることがある。**
