## ライセンスについて

- **MIT** … 著作権表示を残せば、商用利用・改変・再配布が自由
- **Apache-2.0** … MITとほぼ同様に自由。加えて特許に関する条項がある

**いずれも商用の受託開発で問題なく使える種類。**
GPLのような「派生物も同じライセンスで公開する義務」があるものは含まれていない。

## 注意

- 上記は**直接指定しているもの**のみ。これらが内部で使う間接的な依存は含まない
- 間接分も含めた完全な一覧が必要な場合は次のコマンドで出力できる

```
npx license-checker --summary
```

- ライブラリを追加・更新したら、この表も更新すること
