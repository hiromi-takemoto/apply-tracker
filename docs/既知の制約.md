# 既知の制約（このアプリができないこと）

- 対象: ApplyTracker
- 作成日: 2026-08-31

**「できること」より「できないこと」を先に書く。**
納品後に「できると思っていた」と言われるのを防ぐため。

## 1. 機能として作っていないもの

| 項目 | 状況 | 備考 |
|---|---|---|
| 募集ページの自動取り込み | **なし** | 手入力のみ。スクレイピングは対象サイトの規約違反になり得るため意図的に作っていない |
| 案件の並び替え | **なし** | 常に登録が新しい順。絞り込みのみ対応 |
| グラフ・統計の表示 | **なし** | 管理者画面の件数表示のみ |
| CSVの取り込み | **なし** | 出力のみ |
| 提案文のAI生成 | **なし** | |
| 複数人での共有・同時編集 | **なし** | 1人1アカウントで、自分のデータだけを扱う |
| 通知メール | パスワード再設定のみ | 締切のリマインド等はない |
| 画像・ファイルの添付 | **なし** | |
| スマホアプリ | **なし** | ブラウザで動く（スマホの画面幅には対応済み） |
| 多言語対応 | **なし** | 日本語のみ |
| ダークモード | **なし** | |

## 2. 運用上の制約

| 項目 | 制約 |
|---|---|
| メール送信 | Supabaseの無料枠を使用。**1時間あたりの送信数に上限がある**。上限に達すると再設定メールが届かない |
| データベース | Supabaseの無料枠。**一定期間アクセスがないとプロジェクトが休止する**ことがある |
| ホスティング | Vercelの無料枠。商用利用には有料プランが必要な場合がある |
| バックアップ | **自動バックアップは設定していない**。必要ならSupabase側で設定する |

## 3. 仕様上そうしていること（不具合ではない）

| 挙動 | 理由 |
|---|---|
| 再設定画面で、未登録のアドレスでも「メールを送りました」と出る | 登録の有無を外部に漏らさないため（アカウント列挙攻撃の対策） |
| 管理者画面に件数しか出ない | 管理者にも他人の案件の中身を見せないため（最小権限の原則） |
| 操作履歴に提案文・メモの本文が出ない | ログに機微な情報を残さないため |
| 一覧の表が横スクロールする | 列を途中で折り返さず読みやすさを優先したため。操作ボタンは右端に固定してある |
| CSVの値の先頭に `'` が付くことがある | Excelが数式として実行するのを防ぐため（CSVインジェクション対策） |

## 4. 動作確認した環境

| | |
|---|---|
| ブラウザ | Chromium系（Playwrightで自動確認） |
| 画面幅 | 375px（スマホ相当）〜 1280px で確認済み |
| Node.js | v22 |

**Safari / Firefox での目視確認は行っていない。**
必要なら受入テスト表をその環境で実施すること。
